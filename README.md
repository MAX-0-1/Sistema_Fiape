## 📌 Sobre el Proyecto

**Fiape** es un proyecto académico enfocado en el desarrollo de una plataforma
de microcréditos inteligentes para emprendedores y pequeños negocios.

El sistema busca ofrecer acceso a créditos incluso a usuarios sin historial financiero tradicional,
utilizando un modelo de evaluación híbrida basado en:
- reputación,
- comportamiento de pagos,
- historial interno,
- y futuras integraciones con inteligencia artificial.

Este repositorio contiene el **frontend** de la aplicación, desarrollado con **Next.js** para brindar
una experiencia moderna, intuitiva

## 🚀 Instalación y Ejecución

### 📋 Requisitos Previos

- Node.js >= 18
- npm / yarn
- Git

---

### 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/TU-USUARIO/Fiape-Sistema.git

# Entrar a la carpeta del proyecto
cd Fiape-Sistema

# Instalar dependencias
npm install
```

---

### ▶️ Ejecutar el Proyecto

```bash
npm run dev
```

Luego abre:

```txt
http://localhost:3000
```

## 🎯 Objetivo del Proyecto

Fiape busca simular una solución fintech moderna orientada a:
- inclusión financiera,
- acceso a microcréditos,
- reputación digital,
- y evaluación alternativa de riesgo crediticio.

El enfoque principal es permitir que usuarios sin historial bancario puedan construir
una reputación financiera progresivamente.
